# Recorded audio sources

Library: VCSL by Versilian Studios and contributing performers.

License: CC0-1.0. Source: https://github.com/sgossner/VCSL

Processing: leading silence trimmed, short excerpts, stereo downmixed to mono, low-pass filtered and resampled to 22,050 Hz, peak normalized, faded at the boundaries, and exported as 16-bit PCM WAV.

The source library labels middle C as C3; pitched playback roots use scientific pitch notation (middle C = MIDI 60). The score and runtime arrangement are original to the project.
