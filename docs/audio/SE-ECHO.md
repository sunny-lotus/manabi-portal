# まなびひろば 効果音の響き・改訂記録

2026-11-03。要望：「効果音もっと神秘的な感じエコーかけて」。

操作音と汽笛に、段々小さく、丸い音色になるエコーを追加。

| 響き | 遅れ | 元の効果音バスに対する音量 | ローパス周波数 |
| --- | --- | --- | --- |
| 直接音 | 0秒 | 0.90 | なし |
| エコー1 | 0.22秒 | 0.26 | 4,600 Hz |
| エコー2 | 0.44秒 | 0.14 | 3,500 Hz |
| エコー3 | 0.68秒 | 0.07 | 2,700 Hz |

フィードバックで繰り返し増幅する方式ではなく、3つの有限な遅延経路。直接音で操作の手応えを残し、後の響きほど小さく・やわらかくする。効果音の音量設定を引き継ぐ。

効果音OFFとタブ非表示時は、発音中の音に加えて遅延経路を切り離し、蓄積したエコーも止める。次回は新しい経路を作り、古い余韻を再生しない。

ケルトBGM v30のファイル・再生経路は維持する。今回のエコーは効果音バスに適用する。

確認：3回のエコーが順に減衰し、高域も弱くなること、フィードバック経路がないこと、汽笛が同じ経路を通ること、BGMの独立、OFF・非表示時の余韻停止と再開時のクリアを検証。ケルトBGMの読み込み・繰り返し、音量設定、汽車のドラッグも確認。
