# まなびひろば 入る音・戻る音の採用記録

2026-11-03

## 試聴から採用まで

- 戻る音：足音の試聴後、「やっぱとことこがもどるおと」により、木の床を駆け寄る足音を採用。
- 入る音：自作ベルの試作・高音版を経て「サイトで探して」。候補を2つ提示し、「２のほうがいいかな」により、BigSoundBankの **Shop doorbell chime（素材番号3588）** を採用。

## 対応

| 操作 | 音 |
| --- | --- |
| エリアへ入る、アプリの紹介画面へ進む | お店の入口のドアベル |
| 紹介画面からエリアへ戻る、ひろばへ戻る | 木の床のトコトコ足音 |
| 「あそぶ」などのリンクを起動する | ドアベルを起動時の合図として使う |

画面の経路変更で前進・後退を判定するため、パンくずだけでなくブラウザーの戻る操作でも対応する。クリックと画面変更の両方で同じ音を二重再生しない。同じ画面への再クリックでは鳴らし直さない。

連続して移動した場合は前の移動音の発音を止めて新しい音へ切り替える。既存の減衰するエコーは効果音の共通経路で1回だけ掛ける。BGM・汽笛・写真の切り替え音は維持する。リンク先への移動で元のページが閉じた場合、そのページの効果音も停止する。

## 戻る足音

- 作者・配布元：[Kenney / Impact Sounds](https://kenney.nl/assets/impact-sounds)、CC0 1.0。
- `Audio/footstep_wood_000.ogg`〜`004.ogg` の5つを使用。
- 0.10、0.30、0.48、0.645、0.80秒に並べ、少しずつ大きくして近づく感じにする。
- モノラルの元音から小さな左右差を付け、ステレオ22.05 kHz / 16-bit PCM WAVへ書き出し。
- [公開音源](../../common/audio/plaza-back-footsteps-v1.wav)：2秒、176,444 bytes。

## 入るドアベル

- 作者：Joseph SARDIN / BigSoundBank。
- [選ばれた素材ページ](https://bigsoundbank.com/carillon-commercant-s3588.html)：Shop doorbell chime、番号3588。
- 原音：公式WAV `https://bigsoundbank.com/UPLOAD/bwf-en/3588.wav`。
- 個別素材ページでCC0表記、加工・ゲームやアプリへの利用・再配布の許可を確認。
- 前後の無音を整理し、音量・端のフェードを調整。音程やベルの鳴り方は変更しない。
- [公開音源](../../common/audio/plaza-enter-doorbell-v1.wav)：約3.533秒、155,870 bytes、モノラル22.05 kHz / 16-bit PCM WAV。

原音・公開音源のハッシュと測定値は [navigation-se-sources.json](navigation-se-sources.json)。試作のドアベルや草の足音は作業環境に保存し、今回の選定結果と区別する。

## 確認

- エリア・紹介画面へ進むとドアベル、戻ると木の足音が1回鳴る。
- 素材の再生速度は1.0で、採用したドアベルの音程を維持。
- 続けて移動した場合の前の発音停止、同じ経路での重複防止を確認。
- 読込失敗時も予備の音で移動を継続。
- OFF時・非表示時の発音とエコー停止、再開時のキャッシュ、ケルトBGM・汽笛・汽車のドラッグを確認。
